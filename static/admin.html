AUTOMATIC CAMERA SYNC

Connect your Nikon folder

Keep Nikon Wireless Transmitter Utility saving camera JPEGs into one folder on this Windows laptop. The small uploader app watches that folder and sends new images to this event automatically.

Windows setup
  1. Download the separate windows-uploader files from the GitHub branch.
  2. Save the downloaded config as config.json in the same folder as uploader.py.
  3. Run install_and_run.bat. Keep that window open while photographing.

The uploader needs Internet access. If the laptop joins the Nikon camera's direct Wi-Fi, it may lose Internet. Use a shared router/hotspot network for both camera and laptop, or a second network adapter/Ethernet for Internet.
