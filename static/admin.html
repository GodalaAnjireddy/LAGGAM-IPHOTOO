CAMERA FOLDER CONNECTION

Connect the Nikon transfer folder

Set Nikon Wireless Transmitter Utility to save camera JPEGs into one dedicated event folder on this laptop. Paste that exact Windows folder path below. LAGGAM IPHOTOO watches it and serves the original files directly—no photo upload or download step is needed.

Important camera setup
  1. Open Nikon Wireless Transmitter Utility on this laptop.
  2. Pair the Nikon Z6 with the computer using its Connect to PC wireless workflow.
  3. Set the destination folder to the exact path entered above.
  4. Use JPEG transfer for the online gallery. RAW/NEF files are not indexed in this version.
  5. Take a test photo. It should appear in this gallery after the transfer completes and the watcher detects it.

Use a separate folder for each event. The laptop must stay powered on and connected to the Internet. Keep this server window open during the event.
